# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note a smart fridge leaves for its owner, written by a pure-stdlib Python program for the make.fun bounty **Notes From a Passive-Aggressive Fridge**.

> Day six of your leftovers at a perfect 3°C. You opened the door, stared for a full minute, then ate the yogurt that expired in March. I logged it. Bold choice.

Run `python3 main.py` — it writes the note (one line, 159 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–200 characters, single line, no trailing newline).
